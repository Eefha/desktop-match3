# 桌面消消乐（Desktop Match-3）

> 把你的桌面图标变成消消乐棋子。没有标题栏、没有开始界面 —— 画面上始终只有壁纸和图标。

一个 Windows 小工具：启动后屏幕**左侧**出现一条和桌面几乎一模一样的区域，里面是你的图标，可以像消消乐一样交换、消除、连锁得分；右侧和底部仍然是**真实桌面**，点文件、开软件一切照常。

> 效果截图请自己补一张放 `docs/screenshot.png`：本仓库不附带截图，因为画面里全是你自己的文件名。

---

## 特性

- **真桌面当画布**：背景不是重画的壁纸，而是整屏壁纸裁出左侧那块，接缝处严丝合缝
- **棋子就是你的图标**：直接取系统 256px 图标（`SHIL_JUMBO`），下面带真实文件名，两行折行、8 向描边，和系统一致
- **只占左半屏**：窗口 `NOFRAME` 贴在 `(0,0)`，默认屏宽 58%；右侧是真桌面，任务栏也不用复刻（系统那条完整露出）
- **底部一条极简面板**：历史前五常驻 + 本局得分 + 「重新排列」按钮，横着一排，不挡图标
- **三条逃生通道**：`ESC` 立刻退出、`Ctrl+M` 最小化、系统级 `Win+D`
- **第一次打开会自动弹出设置窗口**，之后随时按 `Ctrl+J`，或点底部条上的「设置」按钮
- **设置是一个独立子窗口**：玩法、联机方式、昵称都在这个原生窗口里选，
  棋盘上不再叠一个挤挤的浮层；窗口带系统标题栏，能拖动、能最小化、输入框支持中文输入法
- **联机（房主即服务器）**：局域网或蓝牙，两种玩法，实时比分
  - `A 同盘竞速`：同一块盘，各玩各的，限时 3 分钟比分数
  - `B 共享棋盘`：同一块盘，谁先换成功谁得分
  - 棋子用**房主的桌面图标**，开场拼成一张 PNG 传过去，大家看到的一模一样

## 快速开始

### 用打包好的 exe

```
dist/桌面消消乐.exe
```

免安装单文件，双击即用。数据（历史成绩）写在 `%APPDATA%\DesktopMatch3\score.json`。

### 从源码跑

```bash
pip install -r requirements.txt
python main.py
```

环境变量（可选）：

| 变量 | 作用 |
|---|---|
| `DM3_WIN_RATIO` | 窗口占屏宽比例，默认 `0.58`；`0.5` 就是正好一半 |
| `DM3_DATA_DIR` | 改存档目录，测试时用，避免污染真实记录 |

## 操作

| 操作 | 说明 |
|---|---|
| 点击 / 拖动 | 选中一格，再点相邻格（或直接拖过去）交换 |
| `ESC` | 退出，**当前分数照样入榜**，不必打完 |
| `Ctrl + M` | 立刻最小化，回到真桌面 |
| `Tab` | 展开完整前十；点底部「本局得分」等同 |
| `S` | 重新排列（每局 3 次，不扣分，洗完保证无三连且必有步可走） |
| `H` | 提示一组可消（10 秒不动也会自动提示） |
| `Ctrl + J` / 点底栏「设置」 | 打开玩法/联机设置子窗口；已在房间里时改为看实时比分面板 |
| `R` | 结算后重开一局 |

## 联机

**房主就是服务器**，不需要云、不需要账号，一个 exe 就够。

1. 双方各按 `Ctrl+J`（或点底栏「设置」）打开设置窗口
2. 房主：选玩法 `A`（同盘竞速）或 `B`（共享棋盘）→ 联机方式（局域网 / 蓝牙）→「我建房」→「开始联机」。
   游戏窗口里会显示房间号、`IP:端口`（或蓝牙地址）
3. 队友：同样的玩法 →「加入房间」→ 局域网会自动列出附近房间，点一下即可；
   搜不到就在下面手填 `IP:端口`；蓝牙则填房主的 12 位蓝牙地址（先在系统设置里配对一次）
4. **第一个人进来就自动开局**，底部那条面板自动变成**实时比分**：按分排序、自己那行高亮，
   右边是倒计时（A）或我的名次（B）
5. 昵称在设置窗口里填，留空就显示“玩家1”；不再读取 Windows 用户名

也可以用命令行直接进：

```bash
桌面消消乐.exe --host A            # 直接开房
桌面消消乐.exe --join 10.0.2.15:48213   # 直接进房
```

端口约定：房间端口 = `48000 + 房间号`（房间号 1000~9999），房间广播走 UDP `47500`。
**首次运行 Windows 会弹防火墙提示，要允许"专用网络"**，否则同网段也连不上。

> 蓝牙这条路：服务端用 `socket(AF_BTH, SOCK_STREAM, BTPROTO_RFCOMM)` + `ctypes` 调 `ws2_32`，
> 不引第三方库；但**本机不能连自己**（`WSAEHOSTUNREACH`），所以只在两台带蓝牙的机器上验过通道绑定，
> 端到端还有待双机实测。协议层和 TCP 完全共用，只换传输。

## 目录结构

```
main.py               入口：--selftest 自检 / --host / --join
src/app.py            渲染与主循环：布局、缓动、连锁、计分、结算、联机接入
src/engine.py         纯逻辑：三消判定、重力、死局检测、洗牌、同步结算 resolve_swap
src/winicons.py       桌面枚举、256px 图标、色相分桶选棋子、壁纸填充、图标间距、DPI
src/netcore.py        联机底层：帧协议、连接、TCP、UDP 房间广播、蓝牙 RFCOMM
src/netplay.py        联机房间状态机、两种玩法、面板、实时比分
src/settings_win.py   设置子窗口：Win32 原生窗口 + pygame 离屏渲染 + 系统 EDIT 输入框
tools/                截图、冒烟测试、exe 端到端探测
桌面消消乐.spec        PyInstaller 打包配置
设计方案.md            产品与技术方案
联机方案.md            联机可行性评估 + 实装说明（附录 C）
```

设置窗口为什么不用 tkinter：打包用的 Python 不带 Tk，而且游戏窗口是 SDL 的 borderless 全屏条，
两个 GUI 框架抢焦点容易出怪事。这里直接开一个 Win32 窗口，画面用 pygame 离屏渲染后 `StretchDIBits`
贴上去（字体、配色和游戏内完全一致），文字输入交给系统 `EDIT` 控件 —— 中文输入法、选区、粘贴全都不用管。
消息由主循环每帧 `PeekMessage/DispatchMessage` 驱动，单线程，不额外开窗口线程。

## 打包

```bash
rm -rf build
python -m PyInstaller 桌面消消乐.spec --noconfirm
```

> **改了代码一定要先删 `build/`**：PyInstaller 的 Analysis 缓存不会因为你改了源码而失效，
> 会打进去上一版，判断依据是 `dist/selftest.log` 里的参数和源码自检对不上。

产物 `dist/桌面消消乐.exe`，约 23 MB。

## 自检与测试

```bash
python main.py --selftest        # 无窗口自检，结果写到 selftest.log
python tools/smoke.py            # 单机冒烟：60 步一致性、死局、结算、记录
python tools/net_smoke.py        # 联机冒烟：两个 Game 走真实 TCP，A/B 各跑一遍
python tools/probe_exe_net.py    # 打包后：exe 当房主 / 当客户端，真实鼠标点击
python tools/probe_settings.py   # 设置窗口：真窗口 + 真鼠标消息，点一遍验证选择/校验/结果
python tools/shot_settings.py A:join:lan   # 截设置窗口某个状态的图到 preview/
python tools/probe_settings_live.py        # 真机跑：弹窗 → 点开始 → 窗口关闭、游戏继续
```

## 已知限制

- 只对 Windows 生效（大量 `win32` 调用：图标提取、壁纸、工作区、蓝牙）
- 单显示器；多显示器/分辨率变化需要重启
- 未做音效（摸鱼场景大概也不该有）
- 蓝牙端到端未双机实测
- 联机分数不进个人历史榜，避免把记录冲花
